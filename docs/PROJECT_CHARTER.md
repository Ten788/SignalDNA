# SignalDNA - Project Charter

ID: VERGE-AI-001
Governance: VERGE v1.7.0
Status: M0 planning

## Objective
Build an original, reproducible neural signal intelligence laboratory using a neural network implemented from first principles.

## Initial Scope
Deterministic synthetic signals; NumPy neural network; gradient verification; classical baseline; signal mutation experiments; visualizations.

## Exclusions
No hardware dependency, paid APIs, pretrained models, industrial diagnostic claims, or production implementation before M0 approval.

## M0 Exit
Approved requirements, architecture, data methodology, verification plan, milestones, and implementation readiness.
